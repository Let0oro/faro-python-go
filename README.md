# Faro - Python y Go para sistemas

Curso interactivo de procesos, sistemas, redes y seguridad defensiva.

## Qué incluye

- enfoque práctico en Python y Go;
- objetivos progresivos de observabilidad y servicios locales;
- pruebas y casos límite;
- pistas escalonadas para investigar por tu cuenta.

## Cómo empezar

```bash
npm install
npm run dev
```

## Construir

```bash
npm run build
```
