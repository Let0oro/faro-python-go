**Objetivo:** tener un entorno reproducible para correr pruebas de Python y Go sin tocar sistemas externos.
**Tiempo estimado:** 45–90 minutos

## Requisitos

- Python 3.11+
- Go 1.22+
- Git
- editor de texto o IDE
- entorno virtual para Python

## Comandos mínimos

```bash
python3 --version
go version
git --version
