## Itinerario actual

**Python:** laboratorio → procesos y snapshots → árbol de procesos → subprocess con límites → integridad de archivos.

**Go:** fundamentos → concurrencia y red → servicio local → pool de trabajadores → HTTP robusto.

Cada lección incluye objetivos, preguntas de predicción, tests o casos que debes construir, pistas graduadas y autorrevisión. Ejecuta las pruebas en tu entorno; las páginas no envían código a un evaluador remoto.

> **Laboratorio autorizado únicamente.** Los ejemplos de red se limitan a `localhost`, fixtures o servicios que tú inicies. No pruebes redes ni sistemas de terceros.
